### 书签更新
```python
import xml.etree.ElementTree as ET

def update_items(input_file,output_file,x):
        tree = ET.parse(input_file)
        root = tree.getroot()

        attributes = {
            "PAGE" : "1",
            "OPEN": "1",
            "FONTSTYLE": "0",
            "COLOR": "4278190080",
            "ZOOMMODE": "0",
            "PARMA": "0,0,0,0"
        }

        # 查找所有的ITEM元素并添加属性
        item_count = 0
        for item in root.iter("ITEM"):
            # 为每个ITEM添加属性，如果属性已存在会被覆盖
            for key, value in attributes.items():
                if key == "PAGE":
                    try:
                        value = str(int(item.get("PAGE")) + x)
                    except:
                        print(item.get("NAME"))
                item.set(key, value)
            item_count += 1

        tree.write(output_file, encoding="utf-8", xml_declaration=True)
        print(f"成功处理 {item_count} 个ITEM元素")
        print(f"处理后的文件已保存至: {output_file}")

if __name__ == "__main__":
    input_xml = "book/input.xml"
    output_file = r"output.xml"
    # x是偏移量，因为目录的页码和PDF的页码不一致
    x = 16

    update_items(input_xml,output_file,x)
```




# 2026-01-14

## 优化方案
使用扫描全能王对书籍图片高清化，虽然提升了整体清晰度，却带来了两个新问题：1.字体边缘残留的噪点像光晕，虽然不明显，但在一定程度上影响阅读体验 2.高分辨率图片占用空间过大，仅两张图片就需1MB存储，而降低分辨率又会导致质量下降，同样影响阅读体验。

为解决这个问题，可以将图片转换为黑白二值格式。这不仅大幅度节省存储空间，还消除了噪点，使文字呈现更加清晰。
这也引出了两个新问题。
1.书籍有些部分无法二值化，比如全彩插图等。解决方法是可以用原图或者灰度图替换。
2.由于图片噪点影响，实际选择二值化的阈值还会存在一些问题。比如，如果阈值高，会导致文字过粗，阈值低，则文字会出现缺块的问题，甚至会同时存在文字过粗和文字缺块的现象，很难找到适合所有图片的阈值。解决方法是使用2bits灰度图。经过测试发现，2bits灰度图的效果对比1bit灰度图有质的提升，在细节上更丰富，阅读体验也更好。而4bits的灰度图已经几乎接近8bits灰度图的效果，对于有渐变效果的插图也有很好的显示效果。综合下来，可以使用2bits作为基底，用4bits作为补充。

实际操作中，开几个文件夹显示各类图片，手动选择并替换图片的过程非常繁琐，预览图片也不方便。因此我（实际上是AI）开发了一个辅助工具来简化流程。

在此基础上也自然想到，可以只替换图片的一小部分。这样既可以显示复杂的插图，也可以保证文本的清晰和大小较小。

此外，随着修图大模型的发展，我发现使用千问的图片大模型的修图效果，要远比普通的算法要好，所以可以先使用AI将原图修复成高清图，然后使用高清图转化成2bits,4bits等的图片，这样生成的灰度图像会更清晰。当然这也可以用浏览器自动化工具来实现。需要注意的是，网页端的布局会改变，所以自动化工具也需要时常调整。

## 优化方案
在需要自行扫描书籍并转化为电子版时，我发现手机近距离拍摄书页这种平面内容时，焦点区域较小，外侧图片会模糊。“夸克扫描王”的多帧合成很好的解决了这一点。并且“去杂质”这个算法效果也很好，所以在扫描时推荐使用这个。
扫描书籍主要用到两个工具：小台灯和手机支架。手机支架是方便拍书，省得手拿着了累。小台灯主是保证拍摄的光线均匀，否则会由于明暗不均导致扫描的文字粗细不均。
扫描时使用自动点击器设置时间自动点击拍摄，不推荐软件自带的“自动拍摄”，因为容易误拍。
扫描时，可以分两次，扫描单页和双页，然后合并。这样相对于一次扫描完的好处是，省去来回移动书，提高每页的扫描效率，降低体力消耗（翻页真的很累人）。实测下来，不仅极大的省力，每页的扫描时间也从10秒降低到6秒。
